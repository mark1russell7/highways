A sweep changes one number option of a strategy at a time. The other options keep their defaults. Each point is one route of one board.

Pick a measure and an option. The chart shows the measured points, the fitted curve and its band. The text under the chart tells the held-out error of the fit. Each board stays in one fold, so the error comes from boards that the fit did not see.

The sweep record

A ratio measure divides each value by the value of the same strategy at its defaults on the same board. The ratio removes the size of the board, so it shows the effect of one option.

The time comes from one process on one computer. It is not a paired time, so compare the times only inside one record.
